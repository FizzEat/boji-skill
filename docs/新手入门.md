# 薄拉图与薄肌生活方式 AI Skill 工具箱（boji-skill）新手入门手册

欢迎来到 **boji-skill**。  
这是一个面向现代打工人、学生党与年轻创作者的**全套身体机能、性张力、精力管理与生活掌控力 AI Skills 工具箱**。  
本项目灵感源自博主 **[邵艾伦 (@AlanShao111)](https://x.com/AlanShao111)** 提出的“薄肌理论”与全套“薄拉图（Boplato）”学说。

你不需要先学会深奥的解剖学，不需要花大钱买私教课，也不需要知道具体该调用哪个工具。把当下的身体困惑、饮食卡点、两性困扰或自律内耗交给 `/boji`，它会替你穿透借口，编排最适合你的通关路径。

---

## 一、 第一次使用：如何开始？

### 极简主入口：`/boji`
第一次使用，只需在支持 Agent 的对话框（如 Claude Code / Antigravity / 豆包 / Codex）中输入：

```text
/boji 新手入门
```
或直接陈述你的真实生理与生活现状：
```text
/boji 我身高 175cm，体重 74kg，平时天天吃外卖，小肚子很明显，
引体向上一个都拉不上去。我想把身材搞好看，该怎么开始？
```

系统会：
1. 自动提取核心数据，识别你所处的身材与代谢象限；
2. 给出当前阶段的核心矛盾定性；
3. 编排 1 个主攻技能与辅助技能；
4. 交付一个今天当下就能完成的**最小物理闭环动作（MVP）**。

## 四、 核心心法：薄拉图 4 大铁律

1. **重力不骗人**：以 60kg 以上自重连续 15 个标准引体向上为终极硬实力坐标，不整虚的。
2. **去消费主义**：一碗兰州牛肉面能解决的营养，不要花 100 块去买伪健康中产轻食。
3. **精力即天命**：把被荷尔蒙和虚妄两性绑架的注意力收缩回来，全仓投资自身硬实力。
4. **听劝即进化**：放弃脆弱自尊，一旦发现旧路走不通，24 小时内光速认错改弦更张。
