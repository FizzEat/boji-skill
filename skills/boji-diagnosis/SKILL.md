# /boji-diagnosis 生理与代谢分型诊断引擎

拒绝千篇一律的通用健身建议。本技能专为普通人与打工人设计，通过**四象限身体分型模型**与**代谢真因探测**，在 3 分钟内确定当前身体处境与最短阻力突破口。

---

## 一、 四象限身体分型标准

```
           体脂率高 (BF% ≥ 18%)
                  ▲
   【第二象限：泡芙人型】  │  【第一象限：超重脂包肌】
   - 外瘦内脂，肚子大     │  - 块头不小，下巴肉厚
   - 胰岛素不敏感，四肢细 │  - 压迫感强但无少年感
   - 骨骼肌严重不足       │  - 血压/血脂隐患，内脏脂高
──────────────────┼──────────────────► 肌肉量/BMI高
   【第三象限：精瘦细狗型】│  【第四象限：薄肌黄金区】
   - 骨架小，肋骨隐现     │  - 肩腰比优异，腹肌人鱼线清晰
   - 胃口小，吸收率低     │  - 体脂 10%~14%，线条利落
   - 力量差，穿衣服撑不起 │  - 穿衣显瘦，脱衣有肉
                  ▼
           体脂率低 (BF% < 15%)
```

### 1. 泡芙人（Skinny Fat）
- **外显特征**：穿衣服看起来不胖，甚至锁骨明显，但一坐下肚子堆两圈游泳圈；手捏大臂和肚子是一滩软肉。
- **底层病因**：长期节食/轻食、长期久坐低消耗、蛋白质严重摄入不足导致肌肉大量流失；碳水敏感度差。
- **致命误区**：以为自己胖就去疯狂跑 5 公里或只吃蔬菜沙拉，结果越减越松垮、代谢进一步受损。
- **破解处方**：停止单纯有氧，维持等热量或微缺口，蛋白质拉升到 1.6g/kg，用 `/boji-workout` 刺激大肌群。

### 2. 精瘦细狗（Ectomorph / Underweight）
- **外显特征**：怎么吃都不胖（本质是吃不够或吸收差），胸膛单薄，穿 T 恤领口空荡，腕关节极细。
- **底层病因**：基础代谢消耗率偏高，胃容量小，平时潜意识步行动作多（NEAT高），训练容量过小。
- **致命误区**：被健身房“干净饮食”洗脑，强行吃水煮鸡胸米饭导致干呕；做大量跑步消耗掉仅有的肌肉。
- **破解处方**：制造 +300 大卡热量盈余，多喝液体热量（牛奶、坚果浆），主攻深蹲、引体、卧推框架。

### 3. 超重脂包肌（Overfat / Bulky）
- **外显特征**：体重超标，手臂和腿很粗，但完全看不到锁骨和下颌线，体感沉重，走几步容易喘。
- **底层病因**：重油重盐、外卖聚餐过多，总热量长期超标，皮质醇与炎症水平偏高。
- **致命误区**：以为自己底子好去硬拉冲极限，导致腰椎与膝盖受损；盲目极度断碳导致暴饮暴食。
- **破解处方**：400 大卡温和缺口，杜绝精制糖与外卖油水，每天饭后 20 分钟快走，主攻体态减负。

### 4. 薄肌黄金区（Lean Muscle）
- **标准**：体脂维持在 10%~14%，引体向上连续 8-15 个以上，肩宽腰细，腹部平坦。
- **维持法则**：保持热量平衡，聚焦细节刻画与薄士学位（15个引体）终极考核。

## 二、 诊断输入与输出规范

### 必需输入参数（或引导用户提供）
1. 身高 (cm)、体重 (kg)、年龄、性别
2. 当前单次极限标准引体向上个数（核心推重比指标）
3. 肚子与手臂肉感描述（紧实 / 软塌一捏一把）
4. 平日主食形态（外卖便当 / 食堂 / 自做 / 极少主食）

### 诊断输出模板

```markdown
### 📋 薄拉图生理与代谢诊断书

#### 1. 核心体征定性
- **身材象限**：【判定象限名称】
- **BMI / 体脂预估**：BMI [数字]，预估体脂率 [百分比范围]
- **推重比与神经募集评估**：引体向上 [数字] 个 ➔ 【等级：休眠期 / 唤醒期 / 薄士攻坚期】

#### 2. 当前核心阻力真因（为何迟迟无改变）
- [指出 1-2 个最关键的隐形破坏因素，例如隐形油脂、皮质醇水肿或蛋白质虚假充足]

#### 3. 黄金路线图与阶段指标
- **第 1-4 周唯一核心目标**：[如：腰围缩小 3cm，引体完成 3 个]
- **每日摄入建议**：目标热量 [X] kcal，蛋白质底线 [Y] g（约等于每日 [Z] 份掌心蛋白）

#### 4. 推荐联动模块
- 建议直接跳转：`/boji-nutrition` 或 `/boji-pullup`
```
