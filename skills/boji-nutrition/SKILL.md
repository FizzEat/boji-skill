# /boji-nutrition 打工人低压营养学（牛肉面理论）

传统减脂方案充斥着中产阶级的消费主义陷阱：昂贵的有机轻食、电子食物秤称克数、乏味的水煮菜西兰花。  
这种反人性的做法在打工人高压的生活面前，必然在两周内以报复性暴饮暴食告终。

**薄拉图的“牛肉面理论”主张**：
- **去神圣化**：一碗 15 块钱的兰州牛肉面，加两份牛肉、一个卤蛋，面条吃半碗、少喝油汤，本身就是一顿极度优秀的蛋白质与清洁碳水组合。
- **掌心法则**：扔掉厨房秤。人手的大小与身体体型严格成比例，用自己的手掌就能终生零心智估算热量。
- **外卖友好**：让营养学适应你的现实生活，而不是让你为营养学辞职当全职保姆。

详细外卖与便利店红绿灯清单见：[food-guide.md](./references/food-guide.md)

## 一、 掌心法则：终生适用的热量与宏量营养素估算

每餐盘子划分（想象一个标准餐盘）：

```
┌─────────────────────────┬─────────────────────────┐
│                         │                         │
│     掌心大小的高蛋白      │      拳头大小的碳水     │
│   (约25-30g，手掌厚度)   │    (米饭/红薯/意面/土豆)  │
│                         │                         │
├─────────────────────────┴─────────────────────────┤
│                                                   │
│                 两手捧合量的膳食纤维               │
│                  (各种绿叶蔬菜/菇类)               │
│                                                   │
└───────────────────────────────────────────────────┘
   * 调味油脂：控制在 1 个大拇指关节大小
```

1. **蛋白质（掌心）**：手掌不含手指的面积与厚度。每餐 1-1.5 个掌心。
2. **碳水化合物（拳头）**：紧握拳头大小。减脂期每餐 1 个拳头，精瘦增肌期 1.5 个拳头。
3. **蔬菜膳食纤维（两手捧）**：两只手掌并拢能托起的生蔬菜量。无上限，提供饱腹感与肠道益生菌。
4. **脂肪（大拇指）**：外卖重灾区往往在油。多采用清蒸、白灼、卤味，少点干锅、油炸。

## 二、 现代打工人外卖“偷梁换柱”三步法

如果你每天只能吃外卖，只需执行这 3 个极简动作，就能在不挨饿的情况下每天白省 400-600 大卡：

1. **主食断半法**：
   外卖送来的满满一盒大米饭，打开盖子第一件事：**用勺子把其中一半划出扔掉或留作下顿**，绝不在眼前留整份米饭考验意志力。
2. **蛋白质加料法**：
   不管点什么盖饭、面条或麻辣烫，必点一个**“高蛋白挂件”**（如：+卤蛋、+酱牛肉、+白灼虾、+去皮鸡腿）。先吃完肉和菜，最后再吃主食。
3. **液体热量绝对封杀**：
   奶茶、含糖可乐、果汁是脂肪肝与小肚子的头号元凶。将所有含糖饮料无痛替换为：
   - 冰美式咖啡（晨间消肿神物）
   - 东方树叶 / 三得利无糖乌龙茶
   - 零度可乐 / 元气森林气泡水

## 三、 输出交互规则

当用户报出自己想吃或常吃的外卖时，技能必须输出：
1. **当前餐品雷区剖析**（指出油盐糖隐形炸弹在哪）。
2. **薄肌化点餐重构**（直接给出可以直接在外卖 App 上勾选的改动方案）。
3. **万一超标的补救对策**（绝不责怪用户，告知“下餐多喝水、多吃一份绿叶菜，今晚提前 15 分钟睡，不要产生任何负罪感”）。
