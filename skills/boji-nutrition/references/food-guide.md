# 外卖与便利店薄肌红绿灯食物指南 (Food Guide Reference)

打工人每天点外卖、逛便利店，如何零心智负担选对食物？请对照以下红绿灯清单：

---

## 一、 常见外卖品类破解公式

| 外卖类型 | 🟢 绿灯必点组合 | 🟡 黄灯限量组合 | 🔴 红灯避坑陷阱 |
| :--- | :--- | :--- | :--- |
| **兰州牛肉面 / 面馆** | 加双份牛肉 + 卤蛋 + 凉拌黄瓜，面条吃半碗，不喝红油高汤 | 正常牛肉面配菜，少喝汤 | 炒拉面、油泼面、羊油泡馍（极度高碳高油） |
| **麻辣烫 / 骨汤烫菜** | 番茄锅或清汤底，大量绿叶菜 + 鲜牛肉片 + 鹌鹑蛋 + 魔芋丝 | 微辣骨汤底，少量豆皮/豆腐泡 | 麻酱拌麻辣拌、油炸油条面筋、方便面饼、过量花生酱 |
| **中式快餐 / 现炒便当** | 木须肉、尖椒牛肉、西红柿炒蛋、白灼生菜，主食米饭分出一半不吃 | 卤肉饭（肉汁少拌）、红烧鸡块（去皮） | 溜肉段、锅包肉、炸鸡排、地三鲜（油炸过油蔬菜） |
| **西式快餐（麦当劳/肯德基）** | 板烧鸡腿堡（去酱）、吉士汉堡、玉米杯、零度可乐 | 麦辣鸡翅（偶尔解馋，去脆皮） | 麦辣鸡腿堡（炸鸡）、大份薯条、麦旋风、含糖可乐 |
| **减脂轻食沙拉** | 香煎牛排/鸡胸轻食，配油醋汁（只倒三分之一） | 糙米饭鸡肉饭 | 蛋黄酱、千岛酱（一勺酱等于两碗米饭热量） |

## 二、 便利店（全家/7-11/罗森）薄肌回血补给站

进便利店无需纠结，直接抓取“3 件套”：
1. **优质蛋白（抓 1-2 样）**：
   - 即食卤鸡胸肉 / 鸡胸肉肠（约 20-25g 蛋白）
   - 卤蛋 / 水煮蛋 2 颗（约 12-14g 蛋白）
   - 盒装酱牛肉 / 卤牛腱子片（约 18-22g 蛋白）
   - 原味无糖酸奶 / 希腊酸奶
2. **复合碳水（抓 1 样）**：
   - 蒸紫薯 / 蒸红薯 / 水煮玉米棒
   - 全麦吞拿鱼饭团（看热量表，脂肪低于 5g）
3. **快乐与饱腹液氮（任选 1 样）**：
   - 零度可乐 / 无糖气泡水 / 东方树叶无糖茶
   - 美式黑咖啡（提神与提高早间脂肪氧化）
